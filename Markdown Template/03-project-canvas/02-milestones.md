# Milestones

Identify checkpoints for the project, like “Prototype RAG runs locally by end of Sprint 2”.

Not to be confused with deliverables or tasks, milestones are checklist items which when reached, ensure the project is running on track. By the end this table will serve as a high-level project schedule.

Expected dates or milestones can be altered slightly, but no drastic changes should be made in Sprint 2. Progress on a milestone will be communicated with associated deliverables, where each milestone must have at least one deliverable.
